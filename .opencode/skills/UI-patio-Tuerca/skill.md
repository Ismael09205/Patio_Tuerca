# Skill: Automotive Marketplace UI --- Soft Minimalism

## Objetivo

Diseñar y mejorar una app de compraventa de vehículos con una interfaz
clara, confiable y moderna, combinando **Soft Minimalism + Automotive
Marketplace UI**.

## Identidad visual

-   **Rojo principal:** `#E31C23` --- acciones principales, estados
    activos y detalles de marca.
-   **Blanco:** `#FFFFFF` --- texto sobre rojo y superficies de
    tarjetas.
-   **Texto principal:** `#202124`.
-   **Texto secundario:** `#6B7280`.
-   **Fondo general:** `#F5F6F8`.
-   **Bordes:** `#E5E7EB`.
-   No usar azul ni marrón como colores de la interfaz.

## Principios de diseño

-   Priorizar fotos de vehículos, precio, marca/modelo y datos clave.
-   Usar espacios amplios, jerarquía tipográfica clara y componentes
    sencillos.
-   Tarjetas blancas con radio de 10--14 px y borde fino o sombra muy
    sutil.
-   Fotografías grandes, preferiblemente con proporción cercana a 16:9.
-   Botones claros, con altura cómoda y radio moderado; botón primario
    rojo con texto blanco.
-   Usar rojo con moderación para que las acciones importantes
    destaquen.
-   Mantener contraste, legibilidad y consistencia entre pantallas.
-   Usar iconos simples y etiquetas discretas para filtros, favoritos y
    estados.

## Evitar

-   No usar claymorphism ni sombras profundas.
-   No aplicar glassmorphism a todas las tarjetas; reservar
    transparencias para elementos flotantes solo si aportan utilidad.
-   No llenar la interfaz de rojo, gradientes, animaciones o adornos.
-   No sacrificar usabilidad ni legibilidad por efectos visuales.

## Aplicación

Aplicar esta identidad de forma consistente en catálogo, búsqueda,
filtros, tarjetas de vehículos, ficha de detalle, favoritos, formularios
y navegación. Antes de añadir un componente nuevo, reutilizar los
patrones visuales existentes y respetar la paleta definida.
